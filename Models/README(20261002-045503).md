# Model Weights

Large trained model checkpoints are intentionally not included in this repository.

Examples of excluded files:

- `*.pt`
- `*.pth`
- `*.ckpt`
- `*.onnx`
- `*.safetensors`

The models can be reproduced by running the corresponding training pipeline with the required dataset.

If trained weights are later distributed, they should be hosted using an appropriate model/file hosting service and accompanied by the relevant license and usage information.
